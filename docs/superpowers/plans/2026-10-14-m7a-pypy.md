# M7a PyPy Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `pyenv install` installs official PyPy binaries on Linux (x64, aarch64) and Windows (x64), each checked against a SHA-256 PyPy published, under each OS's drop-in names.

**Architecture:** CI evaluates upstream's PyPy definitions with stub python-build functions (in a container with no network) and reads pypy.org's pages, producing two tables (`crates/pyenv/pypy/linux.tsv`, `windows.tsv`) that rpyenv embeds. Linux turns a table row into a one-line definition the existing interpreter and builder run, plus a new `pypy` build step; a user's own PyPy definition is evaluated with `bash` at run time. Windows adds PyPy rows to `pyenv update` and a PyPy-zip install path whose hash comes from the table, or for a release newer than the table, from pypy.org's checksum page.

**Tech Stack:** Rust 1.96 (crate `pyenv`), bash (the stub evaluator), Python 3 (CI scripts, `unittest`), GitHub Actions, docker/podman.

**Spec:** `docs/superpowers/specs/2026-10-14-m7a-pypy-design.md` (approved 2026-10-14). Read it before any task.

## Global Constraints

- Linux names are upstream's (`pypy3.11-7.3.20`); Windows codes are pyenv-win's (`pypy3.11-v7.3.20-win64`).
- GraalPy stays refused; PyPy `-src`, nightlies (`*-c-jit-latest`) and `pypy-dev` are refused with `PyPy source and nightly builds are not supported`.
- No install ever reads pypy.org's checksum page for a version in rpyenv's table; a Windows file with no published SHA-256 is never installed (no warning path).
- Tables and lists live in `crates/pyenv/pypy/`: `linux.tsv`, `windows.tsv`, `linux-unpublished.txt`, `linux-unsupported.txt`. The evaluator is `crates/pyenv/src/install/pypy_eval.sh`.
- Debug-only test overrides (release builds ignore them): `RPYENV_TEST_PYPY_TABLES` (folder with `linux.tsv`/`windows.tsv`), `RPYENV_TEST_PYPY` (base URL for `versions.json`, `checksums.html` and zips). Tests never reach the network.
- `MIN_PAGE_HASHES = 500` in both `ci/pypy_tables.py` and `install::pypy`.
- Commits: one line with `git commit -m "<message>"`, or a message file `C:\tmp\cm_<random>.txt` with `-F`. No `Co-Authored-By`, no `Claude-Session`, no attribution lines of any kind. No heredocs in git commands.
- Never run `pyenv`, pyenv-win or upstream pyenv without `PYENV`, `PYENV_ROOT`, `PYENV_HOME` (and `HOME`) pointing at a scratch folder. The real roots are `C:\Users\JM\.pyenv\pyenv-win` and `/home/jm/.pyenv`: never write there.
- Python: run with `python` on Windows, `python3` in WSL; every text `open()` passes `encoding='utf-8'`; helper scripts go in `C:\tmp\<name>.py`.
- WSL: never put `$VARS` in a `wsl … bash -c "…"` command line; run script files with `wsl -d Debian --exec /usr/bin/bash /mnt/c/tmp/<x>.sh`.
- Comments and messages match the surrounding code's style: plain sentences, the spec section in parentheses where a rule comes from it.

```bash
#!/usr/bin/env bash
# Evaluates one python-build PyPy definition for one architecture without installing anything
# (M7a design §4): python-build's functions are stubs that record what the definition would
# install. ci/pypy_tables.py runs it over the vendored definitions in a container with no
# network; rpyenv runs it (`bash -c "$script" pypy_eval <file> <arch>`) for a user's own PyPy
# definition, which upstream would source with bash too.
#
#   pypy_eval.sh <definition file> <pypy architecture>
#
# Prints one line: `ok <package> <url>#<sha256> <step>...`, `no-binary` (the definition stopped
# without installing, as upstream's "binary distribution … not available" error does), or
# `unsupported <reason>`. No temporary files, so it runs on a read-only file system.
if [ $# -ne 2 ]; then
  echo "usage: pypy_eval.sh <definition file> <arch>" >&2
  exit 2
fi
out=$(
  (
    pypy_architecture() { echo "$PYPY_EVAL_ARCH"; }
    install_package() { echo "PKG $*" >&3; }
    install_zip() { echo "PKG $*" >&3; }
    colorize() { printf '%s' "$2"; }
    require_osx_version() { return 1; }
    command_not_found_handle() { echo "MISSING $1" >&3; return 127; }
    PYPY_EVAL_ARCH=$2
    # shellcheck disable=SC1090
    source "$1"
  ) 3>&1 >/dev/null 2>&1
)
rc=$?
missing=$(printf '%s\n' "$out" | sed -n 's/^MISSING //p' | head -n 1)
pkgs=$(printf '%s\n' "$out" | grep -c '^PKG ')
if [ -n "$missing" ]; then
  echo "unsupported calls $missing"
elif [ "$pkgs" -eq 1 ] && [ "$rc" -eq 0 ]; then
  line=$(printf '%s\n' "$out" | sed -n 's/^PKG //p')
  pkg=${line%% *}
  rest=${line#* }
  url=${rest%% *}
  steps=${rest#"$url"}
  steps=${steps# }
  hash=${url##*#}
  if [ "$hash" = "$url" ] || [ ${#hash} -ne 64 ] || [ -n "${hash//[0-9a-f]/}" ]; then
    echo "unsupported no sha256 in $url"
  elif [ -z "$steps" ]; then
    echo "unsupported no build steps in $pkg"
  else
    echo "ok $pkg $url $steps"
  fi
elif [ "$pkgs" -eq 0 ] && [ "$rc" -ne 0 ]; then
  echo "no-binary"
else
  echo "unsupported $pkgs packages, exit $rc"
fi
```

```python
"""Builds the PyPy tables rpyenv embeds (M7a design §4.1, §5.1).

  python3 ci/pypy_tables.py --share <python-build share dir> --pages <dir> [--engine docker|podman|local] [--write] [--write-lists]

--share is the vendored crates/pyenv/python-build/share; --pages holds pypy.org's
versions.json and checksums.html, fetched by the caller. The upstream definitions are run by
crates/pyenv/src/install/pypy_eval.sh with stub python-build functions, in a container with no
network and a read-only file system (`local` runs bash directly: tests only). Any failure exits
1 before anything is written. Without --write it reports whether the tables would change.
"""
import argparse
import os
import subprocess
import sys

REPO = os.path.dirname(os.path.dirname(os.path.abspath(__file__)))
DEST = os.path.join(REPO, "crates", "pyenv", "pypy")
EVAL = os.path.join(REPO, "crates", "pyenv", "src", "install", "pypy_eval.sh")
ARCHES = ("linux64", "linux-aarch64")
IMAGE = "debian:trixie-slim"
LOOP = 'for n in "$@"; do for a in linux64 linux-aarch64; do printf "%s\\t%s\\t" "$n" "$a"; bash "$EVAL" "$DEFS/$n" "$a"; done; done'


def pypy_names(share):
    """Every `pypy*` definition file in `share`, sorted (C order)."""
    return sorted(n for n in os.listdir(share) if n.startswith("pypy") and os.path.isfile(os.path.join(share, n)))


def evaluate(share, names, engine):
    """{(name, arch): verdict line} for each binary definition in `names` and each of ARCHES."""
    if not names:
        return {}
    if engine == "local":
        cmd = ["bash", "-c", LOOP, "_", *names]
        env = dict(os.environ, EVAL=EVAL, DEFS=share)
    else:
        cmd = [engine, "run", "--rm", "--network", "none", "--read-only",
               "-v", f"{os.path.abspath(share)}:/defs:ro", "-v", f"{EVAL}:/eval.sh:ro",
               "-e", "EVAL=/eval.sh", "-e", "DEFS=/defs", IMAGE, "bash", "-c", LOOP, "_", *names]
        env = None
    out = subprocess.run(cmd, capture_output=True, text=True, check=True, env=env).stdout
    verdicts = {}
    for line in out.splitlines():
        name, arch, verdict = line.split("\t", 2)
        verdicts[(name, arch)] = verdict
    want = {(n, a) for n in names for a in ARCHES}
    if set(verdicts) != want:
        raise RuntimeError(f"the evaluator answered for {len(verdicts)} of {len(want)} definition/arch pairs")
    return verdicts


def linux_rows(names, verdicts):
    """[(name, arch, verdict)] for every name: `-src` ones are `unsupported source build`."""
    rows = []
    for n in names:
        for a in ARCHES:
            rows.append((n, a, "unsupported source build" if n.endswith("-src") else verdicts[(n, a)]))
    return rows


def render_linux(rows):
    head = ("# Generated by ci/pypy_tables.py from upstream's PyPy definitions (M7a design §4.1).\n"
            "# <name>\\t<arch>\\t<verdict of crates/pyenv/src/install/pypy_eval.sh>\n")
    return head + "".join(f"{n}\t{a}\t{v}\n" for n, a, v in rows)
```

```python
DOWNLOADS = "https://downloads.python.org/pypy/"
# Fewer pairs than this means the page's layout changed (1021 on 2026-10-14). Same number as
# install::pypy::MIN_PAGE_HASHES.
MIN_PAGE_HASHES = 500
HASH = re.compile(r"[0-9a-f]{64}")
FILE = re.compile(r"pypy[A-Za-z0-9_.\-]*\.(?:zip|tar\.bz2|tar\.gz)")
# pyenv-win's own pattern for PyPy zips (pyenv-install-lib.vbs regexJsonUrl), win64 only.
WIN = re.compile(r"^(pypy(\d+)\.(\d+)-v(\d+(?:\.\d+){0,2}))-win64\.zip$")


def page_hashes(html):
    """{file: sha256} from pypy.org's checksum page: tags removed, then each `<64 hex> <pypy
    file>` pair of words. install::pypy::page_hashes does the same."""
    words = re.sub(r"<[^>]*>", " ", html).split()
    out = {}
    for a, b in zip(words, words[1:]):
        if HASH.fullmatch(a) and FILE.fullmatch(b) and out.setdefault(b, a) != a:
            raise ValueError(f"pypy.org's checksum page gives two SHA-256 values for {b}")
    if len(out) < MIN_PAGE_HASHES:
        raise ValueError(f"pypy.org's checksum page has {len(out)} SHA-256 lines, fewer than {MIN_PAGE_HASHES}: has its layout changed?")
    return out


def windows_rows(versions_json, sums):
    """[(code, url, sha256)] for the zips pyenv-win lists that have a published hash, in
    pyenv-win's order: Python version, then PyPy version."""
    rows = {}
    for rel in json.loads(versions_json):
        for f in rel.get("files", []):
            m = WIN.match(f.get("filename", ""))
            if not m:
                continue
            url = f["download_url"]
            if url != DOWNLOADS + f["filename"]:
                raise ValueError(f"{f['filename']}: download_url {url} is not under {DOWNLOADS}")
            if f["filename"] in sums:
                rows[m.group(1)] = (url, sums[f["filename"]])

    def key(code):
        m = WIN.match(code + ".zip")
        return (int(m.group(2)), int(m.group(3)), tuple(int(x) for x in m.group(4).split(".")))
    return [(c, *rows[c]) for c in sorted(rows, key=key)]


def render_windows(rows):
    head = ("# Generated by ci/pypy_tables.py from pypy.org's versions.json and checksums.html (M7a design §5.1).\n"
            "# <pyenv-win code>\\t<url>\\t<sha256>\n")
    return head + "".join(f"{c}\t{u}\t{h}\n" for c, u, h in rows)


def check_linux(rows, sums, unpublished, unsupported):
    """Error lines: an `ok` row whose file pypy.org lists with another hash, or doesn't list and
    linux-unpublished.txt doesn't name; an unexpected `unsupported` row; a stale list entry."""
    errors, seen_files, seen_names = [], set(), set()
    for name, arch, verdict in rows:
        w = verdict.split()
        if w[0] == "ok":
            base, _, sha = w[2].partition("#")
            file = base.rsplit("/", 1)[1]
            seen_files.add(file)
            if file in sums and sums[file] != sha:
                errors.append(f"{name} {arch}: upstream's SHA-256 for {file} differs from pypy.org's")
            elif file not in sums and file not in unpublished:
                errors.append(f"{name} {arch}: {file} is not on pypy.org's checksum page and not in linux-unpublished.txt")
        elif w[0] == "unsupported" and not name.endswith("-src"):
            seen_names.add(name)
            if name not in unsupported:
                errors.append(f"{name} {arch}: {verdict} (add a stub, or list it in linux-unsupported.txt)")
    errors += [f"linux-unpublished.txt: {f} is no longer in any definition" for f in sorted(unpublished - seen_files)]
    errors += [f"linux-unsupported.txt: {n} is no longer unsupported" for n in sorted(unsupported - seen_names)]
    return errors


def read_list(name):
    p = os.path.join(DEST, name)
    if not os.path.exists(p):
        return set()
    with open(p, encoding="utf-8") as f:
        return {l.strip() for l in f if l.strip() and not l.startswith("#")}


def main(argv):
    p = argparse.ArgumentParser()
    p.add_argument("--share", required=True)
    p.add_argument("--pages", required=True)
    p.add_argument("--engine", default="docker", choices=["docker", "podman", "local"])
    p.add_argument("--write", action="store_true")
    p.add_argument("--write-lists", action="store_true",
                   help="first run only: write linux-unpublished.txt and linux-unsupported.txt from what it finds")
    a = p.parse_args(argv)
    with open(os.path.join(a.pages, "checksums.html"), encoding="utf-8") as f:
        sums = page_hashes(f.read())
    with open(os.path.join(a.pages, "versions.json"), encoding="utf-8") as f:
        win = windows_rows(f.read(), sums)
    names = pypy_names(a.share)
    rows = linux_rows(names, evaluate(a.share, [n for n in names if not n.endswith("-src")], a.engine))
    if a.write_lists:
        unpublished = {v.split()[2].partition("#")[0].rsplit("/", 1)[1] for _, _, v in rows if v.startswith("ok ")} - set(sums)
        unsupported = {n for n, _, v in rows if v.startswith("unsupported") and not n.endswith("-src")}
        os.makedirs(DEST, exist_ok=True)
        for fname, items, what in (("linux-unpublished.txt", unpublished, "files pypy.org's checksum page doesn't list"),
                                   ("linux-unsupported.txt", unsupported, "binary definitions the stubs can't evaluate")):
            with open(os.path.join(DEST, fname), "w", encoding="utf-8", newline="\n") as f:
                f.write(f"# Upstream PyPy {what} (M7a design §4.1); reviewed by hand.\n")
                f.write("".join(f"{i}\n" for i in sorted(items)))
    errors = check_linux(rows, sums, read_list("linux-unpublished.txt"), read_list("linux-unsupported.txt"))
    for e in errors:
        print(f"error: {e}", file=sys.stderr)
    if errors:
        return 1
    tables = {"linux.tsv": render_linux(rows), "windows.tsv": render_windows(win)}
    changed = []
    for fname, text in tables.items():
        path = os.path.join(DEST, fname)
        old = open(path, encoding="utf-8").read() if os.path.exists(path) else None
        if old != text:
            changed.append(fname)
            if a.write:
                with open(path, "w", encoding="utf-8", newline="\n") as f:
                    f.write(text)
    print(f"linux.tsv: {len(rows)} rows; windows.tsv: {len(win)} rows; changed: {', '.join(changed) or 'none'}")
    return 0 if a.write or not changed else 1


if __name__ == "__main__":
    sys.exit(main(sys.argv[1:]))
```

```rust
//! PyPy (M7a design, docs/superpowers/specs/2026-10-14-m7a-pypy-design.md): the tables CI
//! builds from upstream's definitions and pypy.org (`crates/pyenv/pypy/`), pypy.org's checksum
//! page for a Windows release newer than the table, and `bash`'s evaluation of a user's own
//! PyPy definition.

use super::fetch::Fetcher;
use std::collections::HashMap;
use std::path::Path;

static LINUX_TSV: &str = include_str!("../../pypy/linux.tsv");
static WINDOWS_TSV: &str = include_str!("../../pypy/windows.tsv");
/// The stub evaluator ci/pypy_tables.py runs over the vendored definitions.
pub const EVAL_SCRIPT: &str = include_str!("pypy_eval.sh");
pub const DOWNLOADS: &str = "https://downloads.python.org/pypy";
pub const CHECKSUMS: &str = "https://www.pypy.org/checksums.html";
/// Fewer pairs than this on the checksum page means its layout changed (1021 on 2026-10-14);
/// ci/pypy_tables.py uses the same number.
pub const MIN_PAGE_HASHES: usize = 500;

#[derive(Debug, Clone, PartialEq, Eq)]
pub enum Verdict {
    /// `url` carries `#<sha256>`, as python-build writes it.
    Ok {
        package: String,
        url: String,
        steps: Vec<String>,
    },
    NoBinary,
    Unsupported(String),
}

fn is_sha256(s: &str) -> bool {
    s.len() == 64 && s.bytes().all(|b| matches!(b, b'0'..=b'9' | b'a'..=b'f'))
}

/// One line of `pypy_eval.sh`'s output.
pub fn parse_verdict(line: &str) -> Result<Verdict, String> {
    let bad = || format!("unreadable PyPy verdict: {line}");
    let mut w = line.split_whitespace();
    match w.next() {
        Some("ok") => {
            let (Some(package), Some(url)) = (w.next(), w.next()) else {
                return Err(bad());
            };
            let steps: Vec<String> = w.map(str::to_string).collect();
            let sha = url.rsplit_once('#').map(|(_, s)| s).unwrap_or("");
            if !is_sha256(sha) || !super::is_plain_name(package) || steps.is_empty() {
                return Err(bad());
            }
            Ok(Verdict::Ok {
                package: package.to_string(),
                url: url.to_string(),
                steps,
            })
        }
        Some("no-binary") if w.next().is_none() => Ok(Verdict::NoBinary),
        Some("unsupported") => Ok(Verdict::Unsupported(
            line.trim_start()["unsupported".len()..].trim().to_string(),
        )),
        _ => Err(bad()),
    }
}

#[derive(Debug, Clone, PartialEq, Eq)]
pub struct LinuxRow {
    pub name: String,
    pub arch: String,
    pub verdict: Verdict,
}

/// `linux.tsv`: `#` comments, then `<name>\t<arch>\t<verdict>` lines.
pub fn parse_linux(text: &str) -> Result<Vec<LinuxRow>, String> {
    text.lines()
        .filter(|l| !l.is_empty() && !l.starts_with('#'))
        .map(|l| {
            let mut f = l.splitn(3, '\t');
            match (f.next(), f.next(), f.next()) {
                (Some(name), Some(arch), Some(v)) if !name.is_empty() && !arch.is_empty() => {
                    Ok(LinuxRow {
                        name: name.to_string(),
                        arch: arch.to_string(),
                        verdict: parse_verdict(v)?,
                    })
                }
                _ => Err(format!("unreadable linux.tsv line: {l}")),
            }
        })
        .collect()
}

#[derive(Debug, Clone, PartialEq, Eq)]
pub struct WinRow {
    pub code: String,
    pub url: String,
    pub sha256: String,
}

/// `windows.tsv`: `#` comments, then `<code>\t<url>\t<sha256>` lines; the URL must be the
/// code's zip in pypy.org's downloads folder.
pub fn parse_windows(text: &str) -> Result<Vec<WinRow>, String> {
    text.lines()
        .filter(|l| !l.is_empty() && !l.starts_with('#'))
        .map(|l| {
            let f: Vec<&str> = l.split('\t').collect();
            match f.as_slice() {
                [code, url, sha]
                    if win_code(code).is_some()
                        && is_sha256(sha)
                        && *url == format!("{DOWNLOADS}/{code}.zip") =>
                {
                    Ok(WinRow {
                        code: code.to_string(),
                        url: url.to_string(),
                        sha256: sha.to_string(),
                    })
                }
                _ => Err(format!("unreadable windows.tsv line: {l}")),
            }
        })
        .collect()
}

/// Debug builds read the tables from `RPYENV_TEST_PYPY_TABLES` (a folder with `linux.tsv` and
/// `windows.tsv`) when it is set; release builds always use the embedded ones.
fn table_text(file: &str, embedded: &'static str) -> Result<String, String> {
    #[cfg(debug_assertions)]
    if let Some(dir) = std::env::var_os("RPYENV_TEST_PYPY_TABLES").filter(|v| !v.is_empty()) {
        let p = std::path::PathBuf::from(dir).join(file);
        return std::fs::read_to_string(&p).map_err(|e| format!("{}: {e}", p.display()));
    }
    let _ = file;
    Ok(embedded.to_string())
}

pub fn linux_table() -> Result<Vec<LinuxRow>, String> {
    parse_linux(&table_text("linux.tsv", LINUX_TSV)?)
}

pub fn windows_table() -> Result<Vec<WinRow>, String> {
    parse_windows(&table_text("windows.tsv", WINDOWS_TSV)?)
}

pub fn linux_verdict<'a>(rows: &'a [LinuxRow], name: &str, arch: &str) -> Option<&'a Verdict> {
    rows.iter()
        .find(|r| r.name == name && r.arch == arch)
        .map(|r| &r.verdict)
}

/// python-build's `pypy_architecture` for the machine rpyenv was built for; PyPy's Linux
/// tables cover x64 and aarch64.
pub fn host_arch() -> Option<&'static str> {
    match std::env::consts::ARCH {
        "x86_64" => Some("linux64"),
        "aarch64" => Some("linux-aarch64"),
        _ => None,
    }
}

/// The one-line definition the interpreter runs for an `Ok` verdict.
pub fn definition_text(package: &str, url: &str, steps: &[String]) -> String {
    format!("install_package \"{package}\" \"{url}\" {}\n", steps.join(" "))
}

/// pypy.org's downloads folder and checksum page. Debug builds honor `RPYENV_TEST_PYPY` (the
/// fake server: `<it>/versions.json`, `<it>/checksums.html`, `<it>/<file>`); with
/// `RPYENV_TEST_PYTHON_ORG` set and it unset they name a closed local port, so a test never
/// reaches the network. Release builds ignore both.
pub fn urls() -> (String, String) {
    #[cfg(debug_assertions)]
    {
        let var = |k: &str| std::env::var(k).ok().filter(|v| !v.is_empty());
        let test = var("RPYENV_TEST_PYPY").or_else(|| {
            var("RPYENV_TEST_PYTHON_ORG").map(|_| "http://127.0.0.1:9/pypy".to_string())
        });
        if let Some(b) = test {
            let b = b.trim_end_matches('/').to_string();
            let page = format!("{b}/checksums.html");
            return (b, page);
        }
    }
    (DOWNLOADS.to_string(), CHECKSUMS.to_string())
}

fn is_pypy_file(f: &str) -> bool {
    f.starts_with("pypy")
        && [".zip", ".tar.bz2", ".tar.gz"].iter().any(|e| f.ends_with(e))
        && f.chars()
            .all(|c| c.is_ascii_alphanumeric() || matches!(c, '.' | '-' | '_'))
}

/// `{file: sha256}` from pypy.org's checksum page: tags removed, then each `<64 hex> <pypy
/// file>` pair of words (ci/pypy_tables.py does the same). Fewer than `MIN_PAGE_HASHES` pairs,
/// or two values for one file, is an error: the layout changed.
pub fn page_hashes(html: &str) -> Result<HashMap<String, String>, String> {
    let mut text = String::with_capacity(html.len());
    let mut in_tag = false;
    for c in html.chars() {
        match c {
            '<' => {
                in_tag = true;
                text.push(' ');
            }
            '>' if in_tag => {
                in_tag = false;
                text.push(' ');
            }
            _ if in_tag => {}
            _ => text.push(c),
        }
    }
    let words: Vec<&str> = text.split_whitespace().collect();
    let mut out: HashMap<String, String> = HashMap::new();
    for pair in words.windows(2) {
        let (h, f) = (pair[0], pair[1]);
        if is_sha256(h) && is_pypy_file(f) {
            if let Some(prev) = out.insert(f.to_string(), h.to_string()) {
                if prev != h {
                    return Err(format!(
                        "pypy.org's checksum page gives two SHA-256 values for {f}"
                    ));
                }
            }
        }
    }
    if out.len() < MIN_PAGE_HASHES {
        return Err(format!(
            "pypy.org's checksum page has {} SHA-256 lines, fewer than {MIN_PAGE_HASHES}",
            out.len()
        ));
    }
    Ok(out)
}

/// pyenv-win's PyPy code `pypy<X>.<Y>-v<version>-win64`: (`[X, Y]`, the version's numbers).
pub fn win_code(s: &str) -> Option<([u64; 2], Vec<u64>)> {
    let rest = s.strip_prefix("pypy")?.strip_suffix("-win64")?;
    let (py, ver) = rest.split_once("-v")?;
    let (x, y) = py.split_once('.')?;
    let num = |p: &str| -> Option<u64> {
        (!p.is_empty() && p.bytes().all(|b| b.is_ascii_digit()))
            .then(|| p.parse().ok())
            .flatten()
    };
    let parts: Vec<u64> = ver.split('.').map(num).collect::<Option<_>>()?;
    (1..=3)
        .contains(&parts.len())
        .then_some(([num(x)?, num(y)?], parts))
}

/// Where `code`'s zip comes from and the SHA-256 it must have (spec §5.2): the table's row, or
/// for a release newer than the table, pypy.org's checksum page.
pub fn win_source(code: &str, f: &Fetcher) -> Result<(String, String), String> {
    if let Some(r) = windows_table()?.into_iter().find(|r| r.code == code) {
        let (base, _) = urls();
        // A test table names the fake server's files by their real URL; serve them from it.
        let url = r
            .url
            .strip_prefix(DOWNLOADS)
            .map(|rest| format!("{base}{rest}"))
            .unwrap_or(r.url);
        return Ok((url, r.sha256));
    }
    let (base, page) = urls();
    let newer = || {
        format!("{code} is newer than this rpyenv's PyPy table and pypy.org's checksum page couldn't be read: update rpyenv")
    };
    let html = f.get_text(&page).map_err(|_| newer())?;
    let sums = page_hashes(&html).map_err(|_| newer())?;
    let file = format!("{code}.zip");
    let sha = sums.get(&file).ok_or_else(|| {
        format!("pypy.org publishes no SHA-256 for {file}, so rpyenv won't install it")
    })?;
    Ok((format!("{base}/{file}"), sha.clone()))
}

/// A user's own PyPy definition, evaluated by `bash` with the stubs CI uses (spec §4.2).
#[cfg(unix)]
pub fn evaluate(def: &Path, arch: &str) -> Result<Verdict, String> {
    let out = std::process::Command::new("bash")
        .arg("-c")
        .arg(EVAL_SCRIPT)
        .arg("pypy_eval")
        .arg(def)
        .arg(arch)
        .stdin(std::process::Stdio::null())
        .stderr(std::process::Stdio::null())
        .output();
    let name = def
        .file_name()
        .map(|n| n.to_string_lossy().into_owned())
        .unwrap_or_default();
    match out {
        Err(e) if e.kind() == std::io::ErrorKind::NotFound => {
            Err(format!("{name} needs bash to be read"))
        }
        Err(e) => Err(format!("{name}: cannot run bash: {e}")),
        Ok(o) => parse_verdict(String::from_utf8_lossy(&o.stdout).trim()),
    }
}
```

```rust
//! A fake PyPy binary tarball for tier-1 tests (M7a): `bin/pypy3.11` answers like fakebuild's
//! interpreter (`-c "import X"`; `-I -m ensurepip` writes `bin/pip3.11`), `bin/pypy3` and
//! `bin/python3.11` link to it, `bin/libpypy3.11-c.so` is executable, and
//! `lib/pypy3.11/site-packages/README` stands in for the library. Unix only.

use std::io::Write;

const PYPY: &str = "#!/bin/sh\ncase \"$1\" in\n  -c) exit 0;;\n  -I) if [ \"$2\" = \"-m\" ] && [ \"$3\" = \"ensurepip\" ]; then\n        d=$(dirname \"$0\"); printf '#!%s\\n' \"$d/pypy3.11\" > \"$d/pip3.11\"; chmod 755 \"$d/pip3.11\"; exit 0\n      fi;;\nesac\nexit 0\n";

fn file(b: &mut tar::Builder<Vec<u8>>, top: &str, path: &str, body: &[u8], mode: u32) {
    let mut h = tar::Header::new_gnu();
    h.set_entry_type(tar::EntryType::Regular);
    h.set_size(body.len() as u64);
    h.set_mode(mode);
    b.append_data(&mut h, format!("{top}/{path}"), body).unwrap();
}

fn link(b: &mut tar::Builder<Vec<u8>>, top: &str, path: &str, target: &str) {
    let mut h = tar::Header::new_gnu();
    h.set_entry_type(tar::EntryType::Symlink);
    h.set_size(0);
    h.set_mode(0o777);
    b.append_link(&mut h, format!("{top}/{path}"), target).unwrap();
}

/// `<top>.tar.bz2` bytes. With `real_pypy` false, `bin/pypy3.11` is a link to a missing file,
/// so `bin/` has no regular `pypy*` executable.
pub fn tarball_bz2(top: &str, real_pypy: bool) -> Vec<u8> {
```

```rust
/// `cp -fR src/. dst`: directories, regular files with their modes, and links as links.
fn copy_tree(src: &Path, dst: &Path) -> std::io::Result<()> {
    std::fs::create_dir_all(dst)?;
    for e in std::fs::read_dir(src)? {
        let e = e?;
        let (from, to) = (e.path(), dst.join(e.file_name()));
        let t = e.file_type()?;
        if t.is_symlink() {
            std::os::unix::fs::symlink(std::fs::read_link(&from)?, &to)?;
        } else if t.is_dir() {
            copy_tree(&from, &to)?;
            std::fs::set_permissions(&to, std::fs::metadata(&from)?.permissions())?;
        } else {
            std::fs::copy(&from, &to)?;
        }
    }
    Ok(())
}

/// The links `build_package_pypy` adds: for each regular, executable, non-link file in `bin/`,
/// in name order, `libpypy*` gets `lib/<name>` → `../bin/<name>` and `pypy*` becomes the target
/// of `bin/python` (the last one wins, as with `ln -fs` in a glob loop).
fn link_pypy(prefix: &Path) -> std::io::Result<()> {
    let (bin, lib) = (prefix.join("bin"), prefix.join("lib"));
    std::fs::create_dir_all(&bin)?;
    std::fs::create_dir_all(&lib)?;
    let mut names: Vec<String> = std::fs::read_dir(&bin)?
        .filter_map(Result::ok)
        .map(|e| e.file_name().to_string_lossy().into_owned())
        .collect();
    names.sort();
    let replace = |at: &Path, target: &str| -> std::io::Result<()> {
        if at.symlink_metadata().is_ok_and(|m| !m.is_dir()) {
            std::fs::remove_file(at)?;
        }
        std::os::unix::fs::symlink(target, at)
    };
    for n in names {
        let m = std::fs::symlink_metadata(bin.join(&n))?;
        if !m.file_type().is_file() || m.permissions().mode() & 0o111 == 0 {
            continue;
        }
        if n.starts_with("libpypy") {
            replace(&lib.join(&n), &format!("../bin/{n}"))?;
        } else if n.starts_with("pypy") {
            replace(&bin.join("python"), &n)?;
        }
    }
    Ok(())
}
```

```rust
/// interpreter reads. The vendored copy uses the table's row; a user's own one that the
/// interpreter can't read is evaluated with `bash`. `None` for every other definition.
fn pypy_text(found: &Found, interpretable: bool) -> Option<Result<String, String>> {
    let builtin = found.origin == Origin::Builtin;
    if !found.name.starts_with("pypy") || (!builtin && interpretable) {
        return None;
    }
    let arch = pypy::host_arch();
    let shown = arch.unwrap_or(std::env::consts::ARCH);
    let verdict = match (&found.origin, arch) {
        (_, None) => Ok(Verdict::NoBinary),
        (Origin::Builtin, Some(a)) => pypy::linux_table().map(|rows| {
            pypy::linux_verdict(&rows, &found.name, a)
                .cloned()
                .unwrap_or(Verdict::NoBinary)
        }),
        (Origin::Dir(d), Some(a)) => pypy::evaluate(&d.join(&found.name), a),
        (Origin::Path(p), Some(a)) => pypy::evaluate(p, a),

    let name = &found.name;
    Some(verdict.and_then(|v| match v {
        Verdict::Ok {
            package,
            url,
            steps,

        Verdict::NoBinary => Err(format!(

        Verdict::Unsupported(_) if builtin => Err(format!(
            "python-build: {name}: PyPy source and nightly builds are not supported"
        )),
        Verdict::Unsupported(why) => Err(format!(
```

```rust
/// pyenv-win's PyPy rows from PyPy's `versions.json` (`pyenv-install-lib.vbs` regexJsonUrl):
/// each `pypy<X.Y>-v<version>-win64.zip`, once, as an x64 zip whose root folder is the code,
/// sorted by Python version, then PyPy version. Names only: `install` gets the hash elsewhere
/// (M7a design §5.1).
pub fn pypy_rows(json: &str) -> Result<Vec<Row>, String> {
    let v: serde_json::Value = serde_json::from_str(json).map_err(|e| e.to_string())?;
    let releases = v.as_array().ok_or("versions.json is not a list")?;
    let mut rows: Vec<(([u64; 2], Vec<u64>), Row)> = Vec::new();
    for f in releases
        .iter()
        .filter_map(|r| r.get("files").and_then(|f| f.as_array()))
        .flatten()
    {
        let (Some(file), Some(url)) = (
            f.get("filename").and_then(|x| x.as_str()),
            f.get("download_url").and_then(|x| x.as_str()),
        ) else {
            continue;
        };
        let Some(code) = file.strip_suffix(".zip") else {
            continue;
        };
        let Some(key) = super::pypy::win_code(code) else {
            continue;
        };
        if rows.iter().any(|(_, r)| r.code == code) {
            continue;
        }
        rows.push((
            key,
            Row {
                code: code.to_string(),
                file: file.to_string(),
                url: url.to_string(),
                x64: true,
                web_install: false,
                msi: false,
                zip_root_dir: Some(code.to_string()),
            },
        ));
    }
    rows.sort_by(|a, b| a.0.cmp(&b.0));
    Ok(rows.into_iter().map(|(_, r)| r).collect())
}
```

```rust
/// A PyPy zip with one top folder, as pypy.org ships them (M7a design §3).
fn pypy_zip(extra_top: bool) -> Vec<u8> {
    let mut entries: Vec<(String, &[u8])> = vec![
        (format!("{PYPY}/python.exe"), b"MZ"),
        (format!("{PYPY}/pypy3.11.exe"), b"MZ"),
        (format!("{PYPY}/Lib/os.py"), b""),
    ];
    if extra_top {
        entries.push(("README.txt".to_string(), b"x"));
    }
    let refs: Vec<(&str, &[u8])> = entries.iter().map(|(n, b)| (n.as_str(), *b)).collect();
    zip_bytes(&refs)
}

/// Serves `/pypy/<PYPY>.zip` and `/pypy/checksums.html` (`page`); returns the server.
fn pypy_server(zip: Vec<u8>, page: Option<Vec<u8>>) -> Server {
    let mut routes: Vec<(String, Vec<Reply>)> = vec![(format!("/pypy/{PYPY}.zip"), vec![Reply::Body(zip)])];
    if let Some(p) = page {
        routes.push(("/pypy/checksums.html".into(), vec![Reply::Body(p)]));
    }
    start_with(move |_| routes)
}
```

```rust
pub struct PypyJob<'a> {
    pub root: &'a Path,
    pub code: &'a str,
    pub force: bool,
    pub fetcher: &'a Fetcher,
}

/// One PyPy zip, end to end (M7a design §5.2): the hash from the table (or the checksum page),
/// the verified download into `install_cache`, the zip's single top folder placed as
/// `versions\<code>`, then ensurepip. Errors leave nothing behind.
pub fn install_pypy(job: &PypyJob, say: &mut dyn FnMut(&str)) -> Result<Done, InstallError> {
    match install_pypy_one(job, say) {
        Err(_) if interrupted() => Err(InstallError::Interrupted),
        r => r,
    }
}

fn install_pypy_one(job: &PypyJob, say: &mut dyn FnMut(&str)) -> Result<Done, InstallError> {
    let code = job.code;
    let versions = job.root.join("versions");
    let msg = InstallError::Message;
    if !super::is_plain_name(code) {
        return Err(msg(format!("invalid version name: {code}")));
    }
    if is_complete_for(&versions.join(code), Flavor::PyenvWin) && !job.force {
        return Ok(Done::Skipped);
    }
    let mut txn = Txn::begin_for(&versions, code, Flavor::PyenvWin).map_err(msg)?;
    let (url, sha256) = super::pypy::win_source(code, job.fetcher).map_err(msg)?;
    let file = format!("{code}.zip");
    let pkg = Package::Zip {
        file: file.clone(),
        url,
        sha256,
    };
    let fetched = fetch_package(&pkg, code, &job.root.join("install_cache"), job.fetcher, &mut |from, to| {
        say(&format!(":: [Downloading] ::  {code} ..."));
        say(&format!(":: [Downloading] ::  From {from}"));
        say(&format!(":: [Downloading] ::  To   {}", to.display()));
    })?;
    say(&format!(":: [Installing] ::  {code} ..."));
    let stage = txn.stage_dir().to_path_buf();
    zipx::extract_zip(&fetched.files[0], &stage).map_err(msg)?;
    let tops: Vec<PathBuf> = std::fs::read_dir(&stage)
        .map_err(|e| msg(format!("{}: {e}", stage.display())))?
        .filter_map(Result::ok)
        .map(|e| e.path())
        .collect();
    let [top] = tops.as_slice() else {
        return Err(msg(format!("{file} does not hold one top folder")));
    };
    if !top.is_dir() {
        return Err(msg(format!("{file} does not hold one top folder")));
    }
    if interrupted() {
        return Err(InstallError::Interrupted);
    }
    txn.place(top)
        .map_err(|e| msg(format!("cannot move {} into place: {e}", top.display())))?;
    let prefix = txn.target();
    // pip, as pyenv-win's install of a folder with `Lib\ensurepip` gets it.
    if prefix.join("Lib").join("ensurepip").is_dir() {
        python(&prefix, &["-m", "ensurepip", "-U", "--default-pip"], "ensurepip", None)
            .map_err(msg)?;
    }
    if interrupted() {
        return Err(InstallError::Interrupted);
    }
    txn.commit()
        .map_err(|e| msg(format!("cannot finish installing {code}: {e}")))?;
    say(&format!(":: [Info] :: completed! {code}"));
    Ok(Done::Installed)
}
```
